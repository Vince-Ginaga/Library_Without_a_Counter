# REQUIREMENTS

This document outlines the Must Have and Should Have requirements of the Library Without a Counter system. It identifies the essential features needed for the system to function and the additional features that can improve its usability. It also includes a real-world limitation that the system must consider to ensure proper and reliable library operations.


# MUST HAVE REQUIREMENTS

These are the essential features that the Library Without a Counter system must have to function properly.

1. **Digital Borrowing and Returning** – Allows students to borrow and return books digitally without relying entirely on manual counter transactions.

2. **Online Book Reservation** – Allows students to view available books and reserve them in advance.

3. **Automated Book Inventory** – Automatically updates book quantities whenever a book is borrowed or returned and tracks book availability.

4. **Borrowing Time Limit** – Assigns a due date to each borrowed book and identifies overdue books.

5. **Student and Librarian Accounts** – Allows students to access their borrowing history, reservations, and due dates, while administrators manage books and student accounts.

6. **Borrowing and Returning Records** – Maintains transaction records containing borrower information, book details, borrowing dates, due dates, and return dates.

# SHOULD HAVE REQUIREMENTS

These are additional features that improve the system but are not essential for its basic operation.

1. **QR Code or Code-Based Scanning** – Allows students to identify books and borrowers using QR codes or manually entered identification codes.

2. **Notifications and Reminders** – Displays reminders about approaching due dates, overdue books, reservation availability, and successful transactions.

3. **Reports and Monitoring** – Allows librarians to view reports about total books, available books, borrowed books, overdue books, and student borrowing activities.

4. **Smart Library Dashboard** – Provides a summary of library activities, book availability, and transaction records.

# REAL-WORLD LIMIT

|| The system must prevent students from borrowing books that are unavailable or already reserved by another student, and must record due dates to identify overdue books. ||
